# Admin Dashboard

A simple admin dashboard interface built using HTML and CSS (primarily CSS Grid). The layout includes a sidebar, header, and main content area with nested grid sections for navigation, search, user info, projects, announcements, and trending items.

## Features

- **Sidebar**  
  - Collapsible navigation area  
  - Branding/logo section  
  - Vertical nav links

- **Header**  
  - Search bar  
  - User profile/info section  
  - Action buttons

- **Main Content**  
  - Grid of project cards  
  - Announcements or alerts section  
  - “Trending” items or statistics panel

- **Responsive Grid Layout (Optional)**  
  - Although the original design is desktop-first, the grid can adjust if resized

## Getting Started

   ```bash
   git clone https://github.com/Jashbaua/dashboard.git
   cd dashboard
```
   Open index.html in your browser

## Technologies Used

- HTML5
- CSS3 (CSS Grid, Flexbox)
- Google Fonts (e.g., Roboto)
- Material Design Icons (SVG icons for nav and action buttons)
